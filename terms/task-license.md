# Task License

> A third-party-verified credential certifying an individual agent's competence for a specific, bounded task domain — the same structure a professional license already provides a human specialist: not a general assurance of good judgment, but a scoped, independently verified certification tied to one defined class of work.

## Extended Definition

Insuring the Autonomous Business established that AIUC-1 functions as the evidence layer that unlocks AI agent liability coverage at the system level — independent verification of a business's overall agentic architecture. That certification answers whether a business's stack is sound as a whole. It does not answer whether one specific agent, performing one specific task, is competent to be trusted with it. A Task License is the credential built to answer that narrower question.

The credential externalizes an architectural discipline that already exists internally. Agent Specialisation establishes agents built with a narrowly defined task domain, a constrained capability set, and a formal cooperation interface for handoff when a task exceeds that domain. A Task License is what happens when that internal design discipline is verified and certified by a party outside the business, the same way a professional's competence within their own firm becomes a portable, externally verified credential the moment they sit for a licensing exam.

The Task Tier a task belongs to determines how much a Task License actually adds. A T1 task is fully automatable with low ambiguity, which limits how much individual competence can vary in the first place. A T2 task requires meaningful judgment within a defined scope — complex enough that competence genuinely varies between agents, bounded enough that a scoped credential can meaningfully certify it. This is where a Task License does real work, and where the credential's value compounds directly into License Grade: the versioned progression of a Task License from junior to senior standing as an agent's verified track record accumulates.

### Application

A Task License is most valuable for T2 tasks — complex enough that competence genuinely varies meaningfully between agents or implementations, and bounded enough that a scoped credential can actually certify it. A credible certifying body verifies, independently: the agent's actual performance record within its claimed task domain, a Recovery Latency and Rollback Cost history specific to that task class, and evidence that the agent's Accountability Trace for that task domain meets a defined evidentiary standard — an extension of AIUC-1's system-level verification model, scoped down to the individual agent and task.

### Context

A Task License answers a narrower and different question than system-level certification like AIUC-1 can answer. AIUC-1 certifies a business's overall AI architecture as a system; a business can hold a strong system-level certification and still have individual agents within its stack performing at wildly different levels of reliability across different task classes. The distinction mirrors exactly how a human professional licensing regime already works: a law firm's overall malpractice history does not certify that any individual associate is competent to file a specific type of filing, the associate's own bar admission does. A Task License externalizes the internal architectural discipline Agent Specialisation already establishes — narrowly defined task domains, constrained capability sets, formal cooperation interfaces — into a credential a third party outside the business actually verifies and stands behind.
